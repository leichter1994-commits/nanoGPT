# Todo Pro (Codex Demo)

Aplicacion de tareas hecha con React + TypeScript + Vite.

## Ejecutar

```bash
npm install
npm run dev
```

## Calidad

```bash
npm run check
```

## Funcionalidades

- Alta de tareas
- Marcar completadas y pendientes
- Eliminar tareas
- Filtros por estado
- Busqueda por texto
- Persistencia local en `localStorage`
- Tests con Vitest + Testing Library

Este proyecto fue agregado dentro de `todo-pro-codex/` para no modificar el flujo principal del repo.
